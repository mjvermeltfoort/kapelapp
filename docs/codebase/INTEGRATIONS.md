- `.env.example` contains placeholders only.
- Frontend fallback key is a non-secret placeholder; no `service_role` or backend secret reference was found.

## 4) Reliability and Failure Behavior

- React Query retries queries once, uses 30-second stale time, and disables focus refetch.
- Direct mutation/API functions have no explicit retry or backoff.
- No explicit request timeout or circuit breaker exists.
- Failed calls throw; pages show errors. Auth bootstrap catches and clears profile state.
- PWA update installs immediately, then reloads page.

## 5) Observability for Integrations

- Auth bootstrap/profile sync use `console.error`.
- Other API failures are surfaced through page state; no centralized logging.
- No metrics, tracing, APM, uptime probe or audit-event pipeline found.
- Missing visibility: RPC latency/failures, RLS denials, auth conversion/failure rates, deployment health.
